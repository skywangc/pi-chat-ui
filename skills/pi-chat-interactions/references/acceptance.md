# 验收清单

按场景验收。每个场景标注了对应参考文档；"合成数据"指用固定 fixture（确定性假数据流）驱动，不要求真实模型。

## A. 滚动跟随（scroll-following.md）

| # | 场景 | 期望 |
| --- | --- | --- |
| A1 | 打开一条长历史会话 | 首帧即定位到底部（无"从中间滚下去"的过程），following=true |
| A2 | 流式输出期间停在底部 | 每帧贴底，无可见跳动；终态 commit（折叠/测高）不改变位置 |
| A3 | 流式期间向上滚一屏 | 立即停在阅读位置；后续 delta 不拉回；出现"回到底部"按钮 |
| A4 | A3 后手动滚回底部 | 距底 ≤48px 时恢复跟随；按钮消失 |
| A5 | A3 后点"回到底部"按钮 | instant 贴底（无 smooth 中间帧），恢复跟随 |
| A6 | 流式中用户上滚后立刻产生大量 delta | 上滚不被吞掉（commit 前对账生效）——这是最容易翻车的用例 |
| A7 | 会话 A 滚到中部 → 切到会话 B → 切回 A | 回到会话 A 上次阅读位置；若 A 当时贴底则仍贴底 |
| A8 | 窗口宽度拖拽改变（流式中） | resize 期间不逐帧抖动；稳定后一次性贴底（仍跟随时） |
| A9 | 长会话顶部继续上滚 | 触发加载更早历史；加载完成后阅读位置不跳动（prepend 锚定） |
| A10 | 键盘 PageUp / 滚动条拖拽 | 与滚轮等效解除/恢复跟随（未分类事件按 user 处理） |
| A11 | 未贴底时观察输入框上方 | 最后一条消息淡出遮罩；贴底后遮罩消失 |

## B. 贴图与附件（attachments-paste.md）

| # | 场景 | 期望 |
| --- | --- | --- |
| B1 | 截图工具截图 → Ctrl+V | 图片入附件条，编辑器不出字；发送后 pi 收到 `prompt.images` |
| B2 | 复制 Excel/飞书表格区域 → 粘贴 | 走文本插入（表格特例），不变成奇怪附件 |
| B3 | 复制 ≥15KB 文本 → 粘贴 | 转为文本附件 |
| B4 | 连续粘贴 9 张图 | 接受 8 张，提示上限（重复触发不叠加提示） |
| B5 | 附件条 chip 点击 | 打开预览 Dialog；Esc 关闭；移除 chip 后 objectUrl 已 revoke |
| B6 | 拖拽文件进输入区 | 高亮反馈（子元素间移动不闪烁）；drop 入同一管线 |
| B7 | 流式进行中带图提交 | 走 steer/follow_up 且 images 随行 |

## C. `/` 命令面板（slash-commands.md）

| # | 场景 | 期望 |
| --- | --- | --- |
| C1 | 空输入输入 `/` | 展开全量目录（extension/prompt/skill 三源），portal 覆盖消息区 |
| C2 | 输入 `/mo` | 模糊过滤排序，selectedIndex 重置 0 |
| C3 | ↑↓/Enter/Tab/Esc | 循环移动 / 选中回填 `/name` / 关闭；方向键不滚动消息区 |
| C4 | 句中输入 URL `https://x.com/a` | `/a` 不触发（非行首/空白后） |
| C5 | 中文输入法 composing | Enter 归输入法，不选中不提交；顿号行首归一触发 `/` |
| C6 | 选中命令回车发送 | pi 收到 `/name args` 原文；扩展命令即时执行，模板被展开 |
| C7 | 扩展热载 / 切换会话后重开面板 | 目录已刷新 |

## D. `@` 文件引用（file-mentions.md）

| # | 场景 | 期望 |
| --- | --- | --- |
| D1 | `@` 空输入 | 列出默认文件（目录沉底，分组预览），node_modules 已排除 |
| D2 | `@cha` | `Chat.tsx` 类文件名列前（前缀/子串优先），路径段子串其次 |
| D3 | `@comp/cha` | 目录段子串命中 relativePath（+25 档生效） |
| D4 | 中文 query `@浏器` | 只连续子串命中，无子序列误报 |
| D5 | `@` 后选文件回车发送 | prompt 文本含 `[label](./relative/path)`；pi 能按路径读到文件 |
| D6 | mention 渲染回显 | 用户消息里的 mention 显示为正常链接（非 `[blocked]`） |
| D7 | 汉字紧邻 `@`（`看@src`） | 触发；`联系邮箱@example.com` 不触发 |
| D8 | 大仓库（≥5 万候选）键入 | 单键无卡顿（worker/二分插入生效） |

## 通用

- 全部合成数据可复跑：视觉与交互用固定 fixture 驱动，标明 fixture 模式；
- 键盘可达性：面板项可 Tab 聚焦/激活，aria-label 完整；
- 不引入运行时外部依赖（CDN/字体/远程资源）；
- 完成时说明：复现状态、参考版本（pi 0.86.1）、验证结果、未覆盖差异。
