# 验收清单

按场景验收。合成数据 = 确定性假会话列表驱动，不要求真实 pi 运行。

## A. 布局与宽度（layout-resize.md）

| # | 场景 | 期望 |
| --- | --- | --- |
| A1 | 首次打开 | 侧栏 264px；拖拽分隔条可在 264px ~ 容器 50% 间调节 |
| A2 | 拖拽缩放 | 无过渡抖动（resizing 期间过渡禁用）；释放后宽度持久化 |
| A3 | 重启应用 | 恢复上次宽度；手动改大的 localStorage 值被钳制 |
| A4 | 分隔条聚焦按 ←/→ | ±16px；Home=264px；End=容器最大；aria-valuenow 同步 |
| A5 | 把窗口缩到很窄 | 会话区 < 360px 且静止 300ms 后侧栏自动收起；恢复宽度为收起前值 |
| A6 | 折叠成窄轨 | 只剩 logo 按钮（hover 换展开图标 + tooltip）；状态重启后保持 |
| A7 | 快捷键（如 ⌘B） | 折叠/展开往返，焦点不丢 |

## B. 行状态（session-list.md + sidebar-model.ts）

| # | 场景 | 期望 |
| --- | --- | --- |
| B1 | 会话流式运行 | 该行转圈（仅 spinner，蓝点红点不并存） |
| B2 | 上次退出时有会话「running」落盘 | 重启后**不转圈**（落盘 running 不产生 loading） |
| B3 | 会话出错 | 红点；实时 phase 恢复后落盘 error 不再兜底 |
| B4 | 未读会话 | 蓝点（unreadAt 数字驱动）；点开即读（乐观消失且不被列表回放覆盖） |
| B5 | 等待授权 / 需要输入 | 注意胶囊（成功色底）；userInput 优先于 permission；count>1 带数量 |
| B6 | 运行中会话 | 排到运行层（列表顶部区），内部按 lastActivityAt 降序 |
| B7 | 后台工作（父回合已收口） | 不转圈但仍在运行层（hasBackgroundWork 参与排序） |
| B8 | 相对时间 | 刚刚 / N 分钟前 / N 小时前 / N 天前；30–60s 全列表同步刷新 |
| B9 | 成员变更（重命名/置顶） | 不改写实时 phase、不触发错误跳序 |

## C. 分组与整理（groups-organize.md）

| # | 场景 | 期望 |
| --- | --- | --- |
| C1 | 切换 organizeBy（分组/项目/时间线） | 立即生效；重启后保持（localStorage 校验回退） |
| C2 | sortBy created/updated | 组内顺序切换 |
| C3 | 组头折叠/展开 | 内容隐藏；折叠集合持久化；新行入折叠组自动展开 |
| C4 | 长列表滚动 | 组头吸顶、相遇推挤让位；吸顶头可交互 |
| C5 | 拖拽行到另一组 | 移入；拖到根层级移出分组；拖拽副本无副作用不响应点击 |
| C6 | 右键「移入分组/移到顶部」 | 与拖拽同一结果（共用视图原语） |
| C7 | 组 7 色标识 | 浅/深主题下对应 token 色 |
| C8 | 大量会话（500+） | 虚拟化滚动流畅；行 key 稳定（spinner 不串行） |

| # | 场景 | 期望 |

## 通用

- 浅/深主题全场景过一遍（token 双套）；
- 键盘全程可达：组头、行、分隔条、rail 按钮均可聚焦激活；
- 无外部资源（CDN/字体/远程请求）；
- 完成时说明：复现状态、参考版本（pi 0.86.1）、验证结果、未覆盖差异。
