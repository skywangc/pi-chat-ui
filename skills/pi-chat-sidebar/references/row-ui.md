# 行 UI：标题走马灯、meta 层级、右键菜单与草稿行

单行 28px 里塞下了标题、指示器、图标、相对时间和动作按钮，全部交互细节都在这层。本文按从左到右、从常态到 hover 展开。

## 标题溢出：走马灯（marquee），不是省略号

分组视图的会话标题**禁用省略号**——右侧渐隐能保留标题连续性，避免和右侧状态元信息挤在一起。完整规格（参考实现语义）：

- 常态：右侧 1.5rem 渐隐遮罩 `linear-gradient(to right, black calc(100% - 1.5rem), transparent)`；
- 溢出判定：以**单份标题的真实排版宽度**（内部 span 的 scrollWidth）对比容器 clientWidth。不能拿挂了遮罩的容器 scrollWidth 判定——走马灯副本会撑大 scrollWidth 导致永远退不出溢出态；
- hover 触发滚动（走马灯）：hover **延迟 1s** 才开始（快速扫过列表不触发）；滚动速度 40px/秒；单程最短 6 秒（短溢出也滚动足够长时间让用户读完）；循环间**停顿 2s**；
- 滚动中遮罩切换为**双边渐隐**（两端各 1.5rem），0.15s 淡入切换；到达终点停 2s 后回卷或循环；
- 原生 `title` 提示必须在组件边界剥掉——hover 走马灯时浏览器原生 tooltip 会遮挡正在滚动的标题；
- 走马灯副本 `aria-hidden="true"`，可访问名仍是完整标题。

普通（非分组）任务列表允许省略号截断 + 原生 title，两套并存时按列表类型选择。

## 行布局（从左到右）

```text
[指示器槽] [标题(走马灯/渐隐)] ......... [右侧 meta 区]
```

- 指示器槽固定宽（`size-4` 容器），无指示器时占位保持对齐：spinner `size-3.5 animate-spin`；error/unread 点 `size-1.5 rounded-full`；
- 标题 `min-w-0` 弹性占据；空标题回退占位文案（「未命名会话」/fork 来源区分）；
- 右侧 meta 区 `ml-auto shrink-0 gap-1.5`，成员见 session-list.md 的三层互斥。

## hover 行为

- hover 背景 `bg-surface-hover`；选中行 `bg-selected`（hover 不覆盖选中）；
- hover 时**常规 meta（指示器+图标+时间）隐藏**，换成动作按钮（关闭会话、打开文件树等，`size` 一致避免宽度跳动）；**交互胶囊（等待用户操作）不隐藏**；
- `hover: none`（触屏）设备：动作按钮常显，不做 hover 换装；
- 键盘 focus-within 与 hover 同权：聚焦行也显示动作按钮（`focus-within` 选择器），保证纯键盘可达。

## 右键菜单（会话行）

完整菜单项（按序）：

| 菜单项 | 行为 |
| --- | --- |
| 移入分组 ▸ | 子菜单列出现有分组（+ 新建分组） |
| 从分组移出 | 仅组内行显示 |
| 移到顶部 | 置顶语义（时间线视图为置顶，分组视图为组内首位） |
| 重命名 | 行内改名或弹窗，写入成员线 name |
| 归档 | 从主列表消失，进入「已归档」视图模式 |
| 标为未读 | 写 unreadAt = now（成员线），行上出现蓝点 |
| 复制工作区路径 / 复制会话文件路径 / 复制日志路径 / 复制会话 ID | 路径类菜单项**懒解析**：首次打开菜单时才解析会话文件/日志路径，不随渲染发 |
| 问题反馈 | 打开反馈表单 |

菜单打开才做重活（懒解析）是通用规则：context menu 的 open 状态是解析动作的开关。

## 草稿行（新会话占位）

- 常驻主列表顶部（或分组视图固定落位），虚线边框区分真实会话：`border-dashed`；
- 状态：激活时 `bg-selected border-primary/35`；未激活 `bg-success/10 border-primary/20`，hover `bg-success/14`；
- 文案固定「新会话」（或带工作区名）；点击 → 切到草稿态输入区（此时输入内容在内存草稿 store 中按 scope 保存，切换会话再切回不丢）；
- 草稿行键盘可达：`role="button"` + Enter/Space 激活；带关闭按钮时 `stopPropagation`；
- 草稿内容的持久化属应用决策：上游 v4 把草稿放内存（跨会话切换保留、跨重启丢弃），仅保留删除任务时清理历史持久化键的 janitor。复刻时二选一都行，但要在文案上诚实（不可静默丢用户输入）。

## 计数与徽章

- 组头计数徽章：组内会话数（`min-w-5` 胶囊），随增删实时更新；
- 置顶组在「分组」模式下显示在最前（如参考样板里的「置顶」组），同样可折叠；
- 未读数不进组头徽章（未读用行蓝点表达），避免同一行两处未读语义。
