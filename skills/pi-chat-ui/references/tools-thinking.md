# 工具调用与思考

## 工具呈现

工具展示按 identity/family 选择 renderer，不是每个工具一张大 JSON 卡。

| 语义 | 紧凑摘要/展开内容 |
|---|---|
| read/搜索 | 文件、路径、查询、结果范围；详情按需展开 |
| bash/执行 | 命令、状态；展开输出，保留换行、ANSI 处理、截断提示 |
| edit/write | 文件和变更摘要；有真实变更数据才显示 diff，不把完整文件伪装 diff |
| 子代理 | 任务、类型、状态、详情入口，见子代理参考 |
| 未知工具 | 名称、真实状态、可展开参数/输出，不丢内容、不崩溃 |

pi 常用小写名称，不同宿主的工具命名可能不同；用显式 registry/adapter，不只匹配 Read/Bash/Agent。

区分参数流入、待执行、运行、成功、失败、中止；等待批准仅在真实扩展提供时出现。toolcall_end 是参数完成，tool_execution_end 才执行终态。成功但空输出不等于未完成。

相同 toolCallId 的消息块、进度、历史结果形成一个可见调用。并行按调用顺序定位、按 ID 回填，不能用“最后一个工具”。图片结果按附件；details 可驱动摘要，不假设所有工具 schema 一样。

长输出保留展开/完整结果途径；源数据已截断就如实提示。重渲染不执行工具；点击摘要仅查看。

## 分组

固定源码默认 Explore/Terminal grouping 开启，Changes grouping 关闭。

- 连续兼容工具才分组，不跨正文/思考边界任意重排。
- 组 ID 锚定首个工具，追加不重建，保留展开/滚动。
- 分组只改变 UI 投影，不改原始消息、不吞失败子项。
- 阶段仍进行与子工具全完成不是同一状态，“尾部工作阶段仍运行”指当前轮仍处在该组且尚未出现后续可见边界；出现后续正文/新阶段后该组结束。不让已结束组无限 running。
- 可先忠实实现单行，再为分类确定的工具加分组；不根据输出自然语言猜身份。

## 思考

从 ThinkingContent.thinking/thinking_delta 构造独立块，维持 content 顺序。无 thinking 不编造思考长文；网络等待提示属于会话状态。

本包规定的思考展示行为：

- streaming/complete 均默认收起；流式空文本不渲染空行。
- trigger 显示流式摘要；展开正文是保留换行的纯文本，不再经过 Markdown。默认 max-height 240px、上距 12px、左距 8px、左边框 1px、内左距 14px；嵌套在已有边界中时去掉重复左线和缩进。
- 用户手动操作后，token 或结束事件不覆盖展开选择。
- 耗时来自真实边界；未知历史耗时不按文字估算，历史回放不重新计时。
- 关闭“显示思考过程”仍保留该轮第一条 reasoning，隐藏后续；按 turn 全序而非虚拟列表可见项判断。用户若要求完全隐藏，作为明确差异实现。
- 内部滚动在底部才跟随，用户上滚后不强拉回底部。

thinkingSignature/thoughtSignature 不可读，不显示。redacted 不泄露不透明载荷，可紧凑提示不可用或按产品要求隐藏；原始数据留在运行时用于续接。
