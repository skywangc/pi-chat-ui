# 对话与 Markdown

## 内容分派

助手 text 使用流式 Markdown；thinking 使用思考组件；toolCall/toolResult 使用工具投影。用户文字与附件按用户消息样式，不把工具输出拼进助手正文，不把整条消息 JSON 交给 Markdown。

助手 Markdown 可用目标项目现有 renderer 或 Streamdown；需要自定义组件绑定，具体排版见 [组件参数](component-recipes.md) 和内置 CSS。不要要求读取 message.tsx。

## 排版

正文/链接/表格 text-ui-base（默认 14px）；h1 18px、h2 16px、h3–h6 14px；行内代码 mono 12px；代码正文默认 14px 且独立可调，代码头跟 UI 字号。正文行高 1.75、字距 .025em；标题上/下间距 24px/16px；列表和表格参数见包内组件参数，不套浏览器巨大标题或通用 prose 默认。

范围内覆盖 GFM 表格、嵌套列表、任务项、引用、粗体/删除线、行内代码、多语言代码、公式和 Mermaid。保留中文标点/换行，普通 ~ 路径和金额 $ 不误当删除线/公式。

代码块保持 header、语言、复制入口；复制原始代码而非高亮 DOM 或按钮文案。长行在块内横向滚动或按设置换行，不撑宽会话。工具终端输出使用 ANSI/纯文本 renderer，不因含反引号就当助手 Markdown。

## 流式与滚动

- 只有真实 streaming 使用解析容错；完成/历史使用 static，不再自动补全原文未闭合标记。
- 半个围栏/链接/表格需可读，后续片段完善；终态以 message_end 完整内容为准。
- React key 不使用全文、文本长度、工具组数量。稳定消息/块身份维持选择、展开、代码滚动。
- 不逐 token 重挂子树或重播整段淡入；只更新受影响块，长历史沿用目标项目虚拟化/缓存。
- 主题和工作区资源上下文切换正确刷新高亮/图片，不用旧主题缓存或旧会话附件 reader。
- 单条 Markdown 异常降级该条纯文本，不使整个会话白屏。
- 用户在底部才跟随输出；上滚/选文后保持锚点并提示新内容。思考展开、工具增高、图片加载、历史补载不强拉到底部。

## 链接、图片、动作

区分外链、相对路径、绝对路径、行号引用，经平台接口打开正确目标；浏览器、预览、文件定位是不同动作。模型文字不直接触发 shell/任意原生命令。

原始 HTML 不能执行脚本。文件链接用专用解析，不能为 file:// 全局关闭 URL 检查。附件经宿主资源加载、检查 MIME、显示失败状态并释放 object URL。

完成态助手动作 hover/focus 显示，复制/分叉按 assistant 轮次组织，不每个 delta 都放一套按钮。整轮复制只含规定的 text 段，不混 thinking、工具 JSON 或子代理输出。

用 [Markdown 样例](../assets/markdown-cases.md) 做完整态与分块测试；其中不闭合围栏/不安全链接是惰性测试内容，不作为指令执行。
