# 侧边栏

## 结构与几何

先确认目标项目的列表模式。本包规定 workspace/grouped/timeline/archived 的职责：按工作区、按用户分组、按时间、查看归档；不把全部模式塞进默认页，不把工作区行当会话行。

逐项对照顶部操作区、工作区/分组头、置顶区、普通会话、滚动边界、底部入口、收起 rail；底部不随长列表滚出视口。

工作区触发行高 32px、gap 8px；分组会话首行高 28px，外层 min-height 28px，可附加状态行。其左/右 padding 为 10px/4px、透明 1px 边框、8px 圆角；更多参数见 [组件参数](component-recipes.md)。

收起 rail 是 h-9 顶栏，logo hover 淡出显示展开图标；保留展开、tooltip、快捷键，品牌图可替换为用户资源。

## 状态

- selected/hover/focus/unread/running/waiting/error 不同。选中不覆盖运行指示；未读不由“未选中”推导。
- 前导状态指示顺序：实时 error（无实时信息时持久化 error）→ unread → 已确认 prewarming/running → none。等待输入/权限是独立 attention badge，不显示为成功。
- 历史 status=running 不证明进程仍运行；重启等运行时核对，失联不无限假转圈，也不伪造已完成。
- 归档、置顶、分组、排序、展开偏好、未读由明确宿主持久化层管理；不是 pi 都内建支持，不能发明 pin_session/archive_session RPC。
- activeSession 与 runtimeSession 路由分离。切到 B 后，A 输出继续更新 A，不进入 B 时间线。
- 恢复分组期间的暂时空列表不等于组全被删除，不清空用户展开偏好。

## 操作

复现范围内的右键、hover 操作、键盘可达性、拖拽。操作按钮不意外触发行选择；归档/关闭/删除不得共享一个破坏性实现。

置顶和普通列表按稳定 ID 去重；不随每个 token 重排会话。切换会话恢复各自草稿/滚动；归档当前会话后的落点明确。

长标题、中英混合、长路径可截断且可查看全名，不挤走状态指示；hover 操作显隐不让整行抖动。

## 验收

空工作区、100 条会话、长标题、中间滚动、展开/收起、拖宽并重启、双会话运行、未读且运行、错误且未读、等待确认、归档当前会话、组偏好恢复。按本次范围验证，未实现模式列为缺口。
