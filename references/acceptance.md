# 验收：按改动选择

## 视觉

同窗口尺寸、DPR、主题、字号和内容，对照本包 assets/reference-board.html 与组件参数。用户另有原应用截图时才追加原版比对；无需运行外部参考应用。明确“包内基准一致”与“原产品像素一致”的区别。

优先侧栏宽度/行密度、正文宽度/字阶/行高、工具/思考缩进、输入框位置、面板边界。覆盖浅/深色、展开/收起、长内容；只对已测 OS 作结论。

## 协议投影

1. 回放 assets/rpc-replay.json：最终文本一次，工具输出 A\nB\n，一张工具卡，agent_end 未 settled 时不提前空闲。
2. 相同 envelope seq 重放不增加字符；不同 seq 的相同 delta 应重复字符，不按内容去重。
3. JSON 拆字节（含中文）、多 JSON 同块、U+2028/2029 字符串，结果一致。
4. SDK 快照路径、RPC delta 路径分别验证，不用错误 shape 假装通过。
5. 工具逆序完成、双会话输出、切换选中，归属正确。
6. message_end/turn_end/agent_end/get_messages 对同一消息不重复渲染。
7. agent_end(willRetry=true) → retry → 输出 → settled，错误/取消/压缩不提前成功。
8. 重连水合不追加副本，旧 generation 无效；隐藏 thinking 不损坏原始历史。

这些需要目标应用测试代码验证，不是 skill 已实现 reducer。

## Markdown 和交互

assets/markdown-cases.md 作为惰性数据，完整渲染后再按不同边界分块；static 原文一致。测围栏、表格、中文、链接、不闭合标记，异常仅影响单条。

流式期间上滚、选文、展开工具/思考、切主题、开子详情，检查跳动/丢选择/动画重播。代码复制等于原代码；整轮复制不带 thinking/工具 JSON。

## 侧栏/子代理

按对应参考验证持久化、未读/运行/错误、等待徽标、组偏好、并行子任务归属、只读详情；打开详情不启动新运行。
